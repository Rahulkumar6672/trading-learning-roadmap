# 📈 Trading Learning Roadmap

A beginner-friendly, step-by-step trading learning course.

## 🎯 Goal

Learn trading from **zero → market basics → charts → analysis → risk management → paper trading → practical decision-making**.

The goal is to understand *why* something happens before ever risking real money.

> **Important:** This repository is for education and practice, not financial advice. No profit is guaranteed in trading.

## 📅 How We Will Learn

Each learning day will have:

1. A simple explanation in Hindi/Hinglish.
2. Important terms and examples.
3. A small quiz/checkpoint.
4. Practical exercises using charts or paper trading when appropriate.
5. A GitHub lesson note.
6. An update to `progress.md`.

## 🚦 Rules

- Understand first; trade later.
- Start with paper trading before considering real-money trading.
- Do not treat leverage as a shortcut to profit.
- Learn stop-loss, position sizing and risk/reward before advanced derivatives.
- Never use money needed for essential expenses.
- Keep a trading journal for every practice trade.
